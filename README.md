## About the hub

UnnamedGamesHub is my central landing page for all the browser games I deploy and maintain. Instead of scattering everything across random links, this project gives each game a clean home, a polished launch experience, and an easy-to-browse catalog.

It is designed to feel like a lightweight game portal with:

- a premium dark-theme storefront look
- quick access to featured and recently added games
- responsive layouts for desktop and mobile
- a single place to browse multiple genres and titles
